# Projeto Integrador III – Aplicativo de Monitoramento do Uso de Cigarro Eletrônico

Este projeto está sendo desenvolvido como parte da disciplina de Projeto Integrador. O desenvolvimento foi iniciado em 2024, durante a etapa I da disciplina, e segue em evolução na etapa III, com previsão de conclusão em 2026. O trabalho é realizado por um grupo de cinco integrantes.

A proposta inicial do projeto surgiu com o objetivo de conscientizar adolescentes sobre os riscos do uso de cigarros eletrônicos, utilizando a tecnologia como ferramenta de apoio para incentivar hábitos mais saudáveis. Ao longo do desenvolvimento, a ideia foi aprimorada para oferecer uma experiência mais interativa e baseada em dados.

Atualmente, o aplicativo permite que o usuário registre informações relacionadas ao seu uso de cigarros eletrônicos. A partir desses registros, são gerados recursos de acompanhamento, como gráficos e estatísticas, possibilitando a visualização da evolução dos dados ao longo do tempo e auxiliando na compreensão dos próprios hábitos.

Além do monitoramento, o aplicativo conta com um sistema de notificações de incentivo, cujo objetivo é estimular a redução do consumo. Essas notificações e os demais recursos de acompanhamento dependem das informações inseridas pelo próprio usuário, tornando sua participação essencial para que o aplicativo possa fornecer análises e feedbacks relevantes.

O projeto está sendo desenvolvido utilizando React Native, buscando oferecer uma aplicação multiplataforma com uma interface intuitiva, acessível e focada na experiência do usuário.

Este repositório reúne o código-fonte e a documentação do projeto, registrando sua evolução ao longo das etapas da disciplina e servindo como base para futuras melhorias e continuidade do desenvolvimento.
